### Added

- Heymarket node with Message (Send, Send Template), Contact (Create or Update),
  and List (Add Contact, Remove Contact) operations.
- Heymarket Trigger node covering message received, message sent, opt-out
  received, incoming call, chat started inbound, chat started outbound, and
  contact updated.
- Heymarket API credential with a connection test that reports which team a key
  belongs to.
