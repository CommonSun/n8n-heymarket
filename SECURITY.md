# Security Policy

## Reporting a vulnerability

Please do not report security issues through public GitHub issues.

Report vulnerabilities per Heymarket's [vulnerability disclosure policy](https://www.heymarket.com/vdp/),
or email [security@heymarket.com](mailto:security@heymarket.com). See also
[heymarket.com/.well-known/security.txt](https://www.heymarket.com/.well-known/security.txt).

## Scope

This policy covers the `n8n-nodes-heymarket` package (the code in this repository).
Issues in the Heymarket platform or API itself are covered by the same disclosure
policy; general product questions go to [help@heymarket.com](mailto:help@heymarket.com).

## Supported versions

Only the latest published version of `n8n-nodes-heymarket` receives security fixes.
